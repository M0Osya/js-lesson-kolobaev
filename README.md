## Классная работа (`index.html`, `script.js`)
1. «Привет, мир» — вывод имени и группы.
2. Переменные и ввод — имя, возраст и город («Ты из …»).
3. Условие — добавлена проверка «меньше 7 → Ты ещё школьник».
4. Цикл — вывод только чётных чисел от 1 до n.
5. Функция — `isEven(x)` и `isPositive(x)`, используются в цикле.
